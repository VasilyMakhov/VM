# Руководство пользователя VM²

Это пошаговая инструкция по работе с маркетплейсом для покупателя, продавца и модератора. Подойдёт для демонстрации проекта на защите и для проверки функциональности.

---

## 1. Начало работы

### 1.1. Запуск

```bash
cd VM
source venv/bin/activate
python app.py
```

Откройте в браузере:

```text
http://127.0.0.1:2911
```

### 1.2. Тестовые аккаунты

| Логин | Пароль | Роль |
|---|---|---|
| `testuser` | `123456` | покупатель |
| `buyer2` | `123456` | покупатель |
| `seller1` | `123456` | продавец |
| `$eller` | `qqqwww123` | продавец |
| `prodavan228` | `123456` | продавец |
| `moderator` | `123456` | модератор |

## 2. Регистрация и вход

### 2.1. Регистрация

1. Нажмите «Регистрация» в шапке сайта.
2. Заполните:
   - логин;
   - почту;
   - имя;
   - фамилию;
   - пароль;
   - роль: «Покупатель» или «Продавец».
3. Нажмите «Зарегистрироваться».

После успешной регистрации вы попадёте на страницу входа.

Ограничения:

- логин и почта должны быть уникальными;
- роль «Модератор» через регистрацию недоступна — её назначают в базе.

### 2.2. Вход

1. Нажмите «Войти».
2. Введите логин и пароль.
3. Нажмите «Войти».

После входа в шапке появится ссылка на личный кабинет с вашим логином.

### 2.3. Выход

Нажмите «Выйти» в шапке или в личном кабинете.

## 3. Покупатель

### 3.1. Каталог

1. Откройте «Каталог».
2. Используйте фильтры:
   - **Категория** — выберите одну из категорий;
   - **Поиск** — часть названия товара;
   - **Цена от / до** — диапазон;
   - **Сортировка** — по цене или алфавиту.
3. Нажмите «Применить».

### 3.2. Карточка товара

Нажмите на изображение или название товара. На странице товара видно:

- описание;
- категорию;
- цену;
- остаток на складах;
- кнопку «Добавить в корзину»;
- кнопку «Добавить в избранное» / «Убрать из избранного».

### 3.3. Избранное

1. Откройте «Избранное» в шапке.
2. Здесь отображаются товары, которые вы отметили.
3. Чтобы убрать товар, откройте его карточку и нажмите «Убрать из избранного».

### 3.4. Корзина

1. Добавьте товар в корзину.
2. Откройте «Корзину».
3. Отметьте галочками товары, которые хотите заказать.
4. Нажмите «Применить выбор».
5. При необходимости:
   - измените количество кнопками «+» / «−»;
   - удалите позицию кнопкой «Удалить».
6. Нажмите «Оформить заказ».

Важно: в заказ попадут **только отмеченные** товары. Сумма справа считается по выбранным позициям.

Ограничения:

- нельзя добавить больше, чем есть на складах;
- нельзя указать количество меньше 1.

### 3.5. Оформление заказа

1. Проверьте список товаров и итоговую сумму.
2. Укажите адрес доставки.
3. Выберите способ оплаты:
   - **СБП** — оплата по QR-коду;
   - **При получении** — оплата при получении.
4. Нажмите «Подтвердить заказ».

Если выбрано СБП, откроется страница оплаты с QR-кодом.

### 3.6. Оплата по СБП

1. Отсканируйте QR-код.
2. Переведите сумму.
3. Нажмите «Я оплатил, честно».

После этого заказ получит статус оплаты «Ожидает проверки». Продавцы должны подтвердить получение оплаты.

### 3.7. Мои заказы

1. Откройте «Мои заказы».
2. Для каждого заказа отображается:
   - номер;
   - дата;
   - сумма;
   - статус заказа;
   - способ оплаты;
   - статус оплаты;
   - статус доставки.
3. Когда заказ передан в доставку, появляется кнопка «Подтвердить получение».

После подтверждения заказ получает статус «Доставлен».

### 3.8. Редактирование профиля

1. Откройте личный кабинет.
2. Нажмите «Редактировать профиль».
3. Измените нужные поля.
4. Если не хотите менять пароль — оставьте поле пустым.
5. Нажмите «Сохранить изменения».

## 4. Продавец

### 4.1. Мои товары

1. Войдите под аккаунтом продавца.
2. В шапке появятся ссылки:
   - «Мои товары»;
   - «Заказы с товарами».
3. Откройте «Мои товары».

Здесь отображаются все товары текущего продавца.

### 4.2. Создание товара

1. Нажмите «Добавить новый товар».
2. Заполните:
   - название;
   - категорию;
   - описание;
   - изображение (JPG, PNG или WebP);
   - цену.
3. Укажите количество на каждом складе.
4. Нажмите «Создать товар».

После создания товар появится в каталоге и в «Мои товары».

Требования:

- все поля обязательны;
- цена неотрицательная;
- количество — целое число ≥ 0;
- изображение должно быть JPG, JPEG, PNG или WebP.

### 4.3. Редактирование товара

1. Откройте «Мои товары».
2. Нажмите на товар или «Редактировать товар».
3. Измените нужные поля.
4. Если не хотите менять изображение — оставьте поле пустым.
5. Нажмите «Сохранить изменения».

### 4.4. Удаление товара

1. Откройте редактирование товара.
2. Нажмите «Удалить товар».
3. Подтвердите удаление.

Если товар уже используется в заказах, удаление будет заблокировано.

### 4.5. Заказы продавца

1. Откройте «Заказы с товарами».
2. Для каждого заказа отображается:
   - номер и дата;
   - покупатель;
   - адрес доставки;
   - ваши товары в заказе;
   - сумма только по вашим товарам;
   - статусы заказа, оплаты и доставки;
   - состояние подтверждения оплаты;
   - состояние передачи в доставку.

### 4.6. Подтверждение оплаты

Кнопка «Подтвердить оплату» появляется, если:

- способ оплаты — СБП;
- оплата ожидает проверки;
- вы ещё не подтвердили оплату;
- заказ не завершён и не отменён.

После подтверждения:

- ваша часть считается подтверждённой;
- если все продавцы подтвердили, заказ переходит в статус «Подтверждён».

### 4.7. Передача в доставку

Кнопка «Передать в доставку» появляется, если:

- заказ оплачен через СБП и вы подтвердили оплату **или** выбрана оплата при получении (подтверждение оплаты не требуется);
- вы ещё не передали товар;
- заказ не завершён и не отменён.

После нажатия:

- ваша часть считается переданной;
- если все продавцы передали товары, заказ переходит в статус «Передан в доставку», а доставка — «В пути».

Сервер дополнительно проверяет оплату: для СБП нельзя передать товар без подтверждения оплаты, а при отклонённой оплате передача запрещена для любого способа. Для оплаты при получении подтверждение продавца не нужно — деньги покупатель отдаёт при получении заказа.

## 5. Модератор

### 5.1. Вход в панель

1. Войдите под аккаунтом `moderator`.
2. В шапке появится ссылка «Панель модератора».
3. Откройте её.

### 5.2. Управление категориями

1. Откройте «Управление категориями».
2. Для добавления нажмите «Добавить категорию».
3. Укажите название и описание.
4. Для изменения нажмите «Изменить».
5. Для удаления нажмите «Удалить».

Если в категории есть товары, удаление будет заблокировано.

### 5.3. Управление складами

1. Откройте «Управление складами».
2. Для добавления нажмите «Добавить склад».
3. Укажите название и адрес.
4. Для изменения нажмите «Изменить».
5. Для удаления нажмите «Удалить».

Если со складом связаны остатки товаров, удаление будет заблокировано.

## 6. Частые вопросы

### Почему нельзя добавить товар в корзину?

Скорее всего, товара нет на складах. Проверьте остаток в карточке товара.

### Почему не появляется кнопка «Подтвердить оплату»?

Проверьте:

- способ оплаты — СБП;
- покупатель нажал «Я оплатил»;
- вы ещё не подтверждали оплату;
- заказ не завершён.

### Почему не появляется кнопка «Передать в доставку»?

Проверьте:

- для СБП — вы подтвердили оплату;
- для оплаты при получении подтверждение оплаты не требуется;
- вы ещё не передавали товар;
- заказ не завершён и оплата не отклонена.

### Почему заказ не виден в «Мои заказы»?

Покупатель видит только свои заказы. Убедитесь, что вы вошли под нужным аккаунтом.

### Почему продавец не видит заказ?

Продавец видит только те заказы, в которых есть его товары. Если заказ состоит из товаров другого продавца, он не отобразится.

### Почему не загружается изображение товара?

Проверьте:

- файл лежит в `static/images/`;
- путь в `IMAGE_URL` начинается с `/static/images/`;
- расширение входит в список разрешённых.

### Почему удаление категории или склада не работает?

На них ссылаются товары или остатки. Сначала удалите или перенесите связанные записи.

### Почему после перезапуска корзина пустая?

Корзина хранится в базе, поэтому должна сохраняться. А вот выбранные галочки хранятся в сессии и могут сброситься.

### Где хранятся пароли?

В базе, в поле `USERS.PASSWORD`, в открытом виде. Это учебное упрощение, не для реального использования.

## 7. Сценарий полной демонстрации

Для защиты можно показать такой сценарий:

1. Войти как `testuser`.
2. Добавить 2–3 товара в корзину.
3. Оформить заказ с оплатой СБП.
4. Нажать «Я оплатил, честно».
5. Войти как `seller1`.
6. Открыть «Заказы с товарами».
7. Подтвердить оплату.
8. Если в заказе есть товары второго продавца — войти как `$eller` и тоже подтвердить.
9. Снова войти как `seller1` и передать товар в доставку.
10. Войти как `testuser` и подтвердить получение.
11. Показать, что заказ стал «Доставлен».
12. Войти как `moderator` и показать управление категориями и складами.

Это демонстрирует:

- каталог;
- корзину;
- заказ;
- оплату;
- мультипродавцовую логику;
- смену статусов;
- роли.
